# Hoody’s Kitchen

ملفات واجهة متجر عربي منزلي متصل بـ Supabase.

## الملفات
- `index.html`: واجهة المتجر والسلة وإرسال الطلبات.
- `admin.html`: لوحة دخول المالك وإدارة المنتجات والطلبات.
- `config.js`: رابط المشروع ومفتاح النشر العام.
- `styles.css`, `admin.css`: التنسيق.
- `app.js`, `admin.js`: وظائف المتجر ولوحة الإدارة.

## تشغيله على GitHub Pages
1. ارفعي كل الملفات الموجودة في هذا المجلد إلى جذر مستودع GitHub.
2. من Settings > Pages اختاري Deploy from a branch ثم `main` و`/ (root)`.
3. بعد التفعيل، رابط المتجر سيكون رابط GitHub Pages الخاص بمستودعك، ولوحة الإدارة على `admin.html`.

## إعدادات Supabase
- لا تضعي `service_role` أو أي مفتاح سري في `config.js`.
- تأكدي أن جداول وسياسات SQL التي أنشأناها موجودة.
- يجب أن يكون حساب المالك موجودًا في `public.admin_users`.
- في Supabase Authentication > URL Configuration أضيفي رابط موقعك ضمن Site URL وRedirect URLs.
- لا تستخدمي الموقع للطلبات الفعلية قبل اختبار إنشاء طلب تجريبي ومراجعة صلاحيات RLS.

ملاحظة: الصور تظهر عند إدخال رابط صورة مباشر للطبق من لوحة الإدارة.
